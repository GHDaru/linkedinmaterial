# Assinatura de texto dos posts GHDARU

Cole **antes das hashtags**, separado do texto por uma linha em branco.

## Padrão (2 linhas)

```
GHDARU · consultoria e implantação de processos agênticos
ghdaru@ghdaru.com.br
```

## Curta (1 linha), para posts com texto longo ou carrossel

```
GHDARU · processos agênticos · ghdaru@ghdaru.com.br
```

## Com chamada (3 linhas), quando o post termina pedindo contato

```
Quer mapear a restrição do seu processo antes de escolher a ferramenta?
GHDARU · consultoria e implantação de processos agênticos
ghdaru@ghdaru.com.br
```

## Regras
- Escreva **GHDARU** sempre em caixa alta. Use o separador `·` (ponto médio), não hífen.
- Não acrescente telefone, site ou CNPJ.
- O e-mail aparece como texto. O LinkedIn nem sempre transforma e-mail em link, então não escreva "clique no e-mail".
- Não use emoji na assinatura.
